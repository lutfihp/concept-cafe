# Git Setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Initialize the project as a git repository, exclude the design handoff folder, commit all tracked files, and push to GitHub as branch `main`.

**Architecture:** Sequential git operations — update .gitignore, init repo, stage and commit everything, add remote, rename branch, push. No source code changes.

**Tech Stack:** Git, GitHub (`https://github.com/lutfihp/concept-cafe.git`)

---

### Task 1: Update `.gitignore`

**Files:**
- Modify: `.gitignore`

- [ ] **Step 1: Add `handoffs/` to `.gitignore`**

Open `.gitignore` and append the following block at the end of the file (after the existing `# brainstorm sessions` section):

```
# design handoff (prototype files, not project source)
handoffs/
```

The full end of the file should look like:

```
# brainstorm sessions
.superpowers/

# design handoff (prototype files, not project source)
handoffs/
```

- [ ] **Step 2: Verify the pattern is correct**

Run:
```bash
cat .gitignore | grep handoffs
```

Expected output:
```
handoffs/
```

---

### Task 2: Initialize repository and make initial commit

**Files:**
- Creates: `.git/` (git repo metadata)

- [ ] **Step 1: Initialize the git repository**

Run:
```bash
git init
```

Expected output:
```
Initialized empty Git repository in D:/Codading Repo/concept-cafe/.git/
```

- [ ] **Step 2: Verify `.gitignore` is working — confirm `handoffs/` and `node_modules/` are excluded**

Run:
```bash
git status --short
```

Expected: `handoffs/` and `node_modules/` do NOT appear in the output. You should see only tracked source files listed with `??` (untracked) or `A` (staged) prefixes. If `handoffs/` appears, the `.gitignore` entry is wrong — go back to Task 1.

- [ ] **Step 3: Stage all tracked files**

Run:
```bash
git add .
```

Expected: no output. All files not matched by `.gitignore` are staged.

- [ ] **Step 4: Verify staged files look correct**

Run:
```bash
git status --short
```

Expected: all lines start with `A ` (staged). Confirm you see files like:
```
A  .eslintrc.json
A  .gitignore
A  CLAUDE.md
A  app/globals.css
A  app/icon.svg
A  app/icon.png
A  app/apple-icon.png
A  app/layout.tsx
A  app/page.tsx
A  components/...
A  docs/...
A  lib/...
A  next.config.mjs
A  package.json
A  package-lock.json
A  postcss.config.mjs
A  tailwind.config.ts
A  tsconfig.json
```

Confirm `handoffs/`, `node_modules/`, `.next/`, `out/`, `*.tsbuildinfo`, and `next-env.d.ts` are NOT listed.

- [ ] **Step 5: Make the initial commit**

Run:
```bash
git commit -m "init: initial project commit"
```

Expected output ends with something like:
```
[master (root-commit) xxxxxxx] init: initial project commit
 N files changed, N insertions(+)
```

---

### Task 3: Link remote and push to GitHub

**Files:**
- No file changes — git remote and branch config only

- [ ] **Step 1: Add the GitHub remote**

Run:
```bash
git remote add origin https://github.com/lutfihp/concept-cafe.git
```

Expected: no output.

- [ ] **Step 2: Verify the remote was added**

Run:
```bash
git remote -v
```

Expected:
```
origin  https://github.com/lutfihp/concept-cafe.git (fetch)
origin  https://github.com/lutfihp/concept-cafe.git (push)
```

- [ ] **Step 3: Rename branch to `main`**

Run:
```bash
git branch -M main
```

Expected: no output. The local branch is now named `main`.

- [ ] **Step 4: Push to GitHub**

Run:
```bash
git push -u origin main
```

Expected output (exact numbers will vary):
```
Enumerating objects: N, done.
Counting objects: 100% (N/N), done.
...
Branch 'main' set up to track remote branch 'main' from 'origin'.
```

If prompted for GitHub credentials, authenticate with your GitHub username and a personal access token (not your password).

- [ ] **Step 5: Verify the push succeeded**

Run:
```bash
git log --oneline origin/main
```

Expected: shows the initial commit hash and message:
```
xxxxxxx init: initial project commit
```
